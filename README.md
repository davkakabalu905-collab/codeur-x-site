# CODEUR X — Site Vitrine Professionnel Multi-Pages

**CODEUR X** est un site vitrine technologique moderne, interactif et captivant pour un groupe de développeurs informatiques. Le site présente les services, le portfolio, l'équipe et permet aux clients de prendre contact facilement.

---

## 🚀 Pages réalisées

| Page | Fichier | Description |
|------|---------|-------------|
| Accueil | `index.html` | Hero animé, stats, services, projets, témoignages, CTA |
| À Propos | `about.html` | Histoire, mission/vision, valeurs, équipe, compétences |
| Services | `services.html` | 6 services détaillés, processus, tarification |
| Portfolio | `portfolio.html` | 9 projets filtrables, galerie interactive, modals |
| Blog | `blog.html` | Articles tech, sidebar, catégories, newsletter |
| Contact | `contact.html` | Formulaire complet, WhatsApp, FAQ, carte |

## ✨ Fonctionnalités Implémentées

### 🎨 Design & Style
- **Thème** : Noir, Bleu tech, Blanc — style futuriste professionnel
- **Typographie** : Poppins (principal) + Roboto Mono (code)
- **Animations** : CSS + JavaScript (scroll reveal, compteurs, marquee, float)
- **Code window** : Fenêtre de code animée dans le hero

### 📱 Responsive Design
- Mobile-first (smartphones, tablettes, desktops)
- **Menu hamburger animé** pour mobile
- Grilles adaptatives (1-4 colonnes selon l'écran)

### ⚙️ Composants Interactifs
- **Navbar fixe** : transparente → glassmorphism au scroll
- **Typed effect** : rotation de textes animée
- **Compteurs animés** : statistiques qui se comptent au scroll
- **Scroll reveal** : apparition progressive des sections
- **Filtres de portfolio** : filtrage par catégorie sans rechargement
- **Modals de projets** : popup détails au clic
- **Tilt cards** : effet 3D au survol
- **FAQ accordéon** : questions/réponses animées
- **Newsletter** : abonnement avec toast de confirmation
- **Success popup** : confirmation après envoi de formulaire
- **Marquee infini** : défilement des technologies

### 📞 Contact
- Formulaire complet (nom, email, téléphone, budget, message)
- **Sélecteur de sujet** visuel (6 catégories)
- **Bouton Email** (mailto)
- **Bouton WhatsApp Direct** (wa.me)
- Icône WhatsApp **flottante** sur toutes les pages
- Carte localisation (Google Maps)
- Bouton **Scroll to Top** 
- Toast notifications

### 🦶 Footer Complet
- Logo + description + réseaux sociaux
- Navigation rapide
- Liste des services
- Informations de contact
- Copyright CODEUR X

## 🛠 Technologies Utilisées

- **HTML5** sémantique
- **CSS3** (Flexbox + Grid + Animations + Variables CSS)
- **JavaScript ES6+** (vanilla, no framework)
- **Font Awesome 6.5** (icônes via CDN)
- **Google Fonts** : Poppins + Roboto Mono
- **Unsplash** : images professionnelles optimisées

## 🔧 Personnalisation Nécessaire

Remplacez les éléments suivants dans tous les fichiers :

| Élément | Remplacement |
|---------|-------------|
| `https://wa.me/NUMERO` | Votre numéro WhatsApp international |
| `contact@codeurx.com` | Votre vrai email |
| `+XXX XXX XXX XXX` | Votre numéro de téléphone |
| `Alger, Algérie` | Votre localisation réelle |
| Noms de l'équipe | Vrais membres de l'équipe |
| Photos de l'équipe | Photos réelles |
| Projets portfolio | Vos vrais projets |
| Prix des services | Vos tarifs réels |

## 🌐 Déploiement

Pour mettre le site en ligne :
1. Allez dans l'onglet **Publish** 
2. Cliquez sur **Publier**
3. Votre site sera en ligne instantanément

## 📊 Performance

- Images optimisées via Unsplash CDN (lazy loading)
- CSS minifiable (variables CSS pour maintenabilité)
- JavaScript léger (vanilla, sans dépendances lourdes)
- Fonts préchargées via Google Fonts
